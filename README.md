## 複数レイヤーのオブジェクト統合（2026-11-06）

1. 左側の「レイヤー」で2つ以上のチェックボックスをONにします。
2. 「◇ オブジェクトを統合」をクリックします。
3. 複数のパーツが1つの「統合オブジェクト」レイヤーに変わります。移動・回転・拡大縮小・複製・素材登録が可能です。

現在のフレームの形状・色・クリッピング・エフェクトをSVGベクターとして統合します。複数色・グラデーション・フォルダー内の素材にも対応します。**フォルダー化と異なり、元のパーツや個別キーフレームは1つのオブジェクトへ固定されます。** 事前保存、または Ctrl+Z で統合前に戻してください。

非表示／ロック中、選択外の子パーツの親になっているレイヤーは事故防止のため統合できません。


### 編集可能なオブジェクト統合（v20）

レイヤーのチェックボックスで、同じフォルダー内で重なり順が連続している2個以上のオブジェクトを選択し、**「◇ オブジェクトを統合」**を押します。元パーツのベクターパス・色・個別のキーフレームを保持した「統合オブジェクト」が作成され、閉じた状態ではまとめて移動・回転・拡大縮小できます。

* **個別編集**：レイヤーの▶、またはプロパティの「中のパーツを編集」で展開します。子パーツを選択後、色、頂点、ベジェ曲線、キーフレームなどを従来どおり変更できます。
* **統合解除**：統合オブジェクトを選択し、「統合解除」を押します。元パーツに戻り、色・パス・アニメーション情報が保持されます。統合後にグループ自体を動かした場合、その動きを子レイヤーにベイクして配置を維持します。
* **互換性**：旧バージョンで作成した一枚のSVGに焼き込む統合（shape.type=`merged`）も表示できます。ただしそのデータには元のパス／色の別情報が残っていないため旧統合は解除できません。新規の統合から非破壊方式となります。
* **見た目の安全性**：違うフォルダーにまたがる選択、間に別レイヤーを挟む選択、外部への親子参照・クリッピングがある場合は変更しません。必要に応じてレイヤー順や選択範囲を調整してください。

## ラフ作画（ラスターレイヤー）
- レイヤー欄の「＋ ラスター」で透明なラスターレイヤーを作成し、上部の「ラフ作画」を選択してください。
- 右側の「ツール」欄でペン／消しゴムをラジオボタン切り替え。各ツールのサイズは独立して記憶します。
- ブラシサイズ（1〜150px）、手振れ補正（0〜100%）をスライダー調整できます。
- 消しゴムは透明消去。ラフ画像はプロジェクトJSONのレイヤーに埋め込まれ、PNG/SVG/PSD書き出しにも含まれます。
- ラスターの描画内容はフレーム共通です（レイヤーの位置や不透明度などのキーフレームは既存機能を使用）。


### 筆圧対応（ラフ作画）

- ペン／消しゴムの両方で筆圧による太さの変化を使用できます。ツール別のブラシサイズは引き続き個別に保持します。
- 右側の「ツール」→「筆圧でブラシの太さを変更」で ON/OFF を切り替えできます（初期値 ON）。
- マウス・通常のタッチ操作は一定のサイズで描画します。筆圧入力は対応機器・ドライバー・ブラウザが必要です。
- 手振れ補正を維持。ペン入力の coalesced events が提供される環境では、移動と筆圧の中間サンプルも取り込みます。

1列のフローティングツールパレットは折りたたみ時と同じ82px幅に統一しました。


### ベクターアウトライン方式への変更
アウトライン生成は従来の画像化・ピクセル輪郭追跡を廃止。選択レイヤーやフォルダーの閉じたベクター図形（パス／楕円／四角）のパスを座標変換して統合し、内部の重複境界を除いた外周から独立した線専用ベクターレイヤーを生成。線幅・線色・内外配置指定に対応。交差位置の検出には数値計算を使いますが、出力線は3次ベジェ曲線として保持します。交点位置でパスを分割するため、追加の制御点が生じる場合があります。ラスター・3D・開いた線・メッシュ・クリッピング・繰り返しは対象外。


### フォルダーアウトラインの処理順修正
フォルダーの可視ベクターレイヤーを内部的に複製し、複製の座標を確定して統合ベクター形状を形成した後、塗りを外して外周パスのみを独立した線レイヤーにしています。元フォルダーは変更しません。曲線の外形を多数の直線で置き換えず、元の3次ベジェ曲線を必要な交点で分割して統合します。交点探索の精度には数値誤差があります。


### ベジェ曲線保持式アウトライン生成（更新）
- 単独のベジェパスは元のアンカーポイントと制御ハンドルから直接曲線を生成します。
- フォルダーは元の図形を変更せずに可視ベクターの内部コピーを用いて統合計算を行い、重なりの内部境界を除去したベジェ曲線の線専用レイヤーを作ります。
- 交差位置は細分化による数値探索で求めますが、出力する線分は直線ポリゴンではなく3次ベジェ曲線です。交点には新たなアンカーが増えます。
- 「内側・中央・外側」は線の中心パスを変形せず、SVGのマスク／クリップによって線の表示位置を切り替えます。
- 対応対象：閉じたパス、楕円、角丸を含む四角形。フォルダー内の描画可能な対象を統合します。
- 制限：ラスター、3D、テキスト未パス化、クリッピング、メッシュ、繰り返し、開いたパスは対象外。完全に同一・接線接触・自己交差などの退化ケースで結果が不安定になる可能性があります。


## リンク付きクローンレイヤー（試作）

レイヤー／フォルダーを選択 → 左パレットの ≡ →「選択レイヤー／フォルダーをクローン」。元データを複製せず参照し、移動・回転・頂点・アニメーションの変更を描画時に自動更新します。クローン側は独立した塗り表示、色、アウトライン、線幅、透明度、追加変形を設定できます。クローンの重複参照を防ぐため、クローンからクローンは生成できません。元データを削除すると参照切れ表示になります。フォルダー参照では全子要素の輪郭を個別に描くため、重なりの内側境界の除去は未対応です。


## フォルダーリンククローン：外周統合
フォルダーをクローンすると、可視の閉じたベクター図形を毎回曲線のまま合成し、重なった内部境界を除いた外周だけにクローン独自のアウトラインを適用します。元フォルダーのオブジェクトを編集すると輪郭も更新されます。ラスター・3D・開いた線画・メッシュ・クリッピング・繰り返しは外周統合の対象外です。複雑な接線、自己交差や非常に多い曲線では計算の制約があります。


## クローン表示・回転軸の修正
クローンは元の形状をキャンバス座標で参照し、表示時にクローンの親座標へ変換してから独自の変形を適用します。初期状態で表示位置が変わらず、アンカーポイントは元の見た目の中心になります。旧版で作られたクローンの原点ピボットはそのまま保存されるため、再作成で中心を設定できます。


## クローン・フォルダー外周統合の判定修正（2026-11-07）

- 以前は内部形式 `rect` / `ellipse` / `path` 以外をエラーにしており、SVG素材や統合済みベクター素材を誤って対象外としていました。
- `svg` / `merged` のSVGパスを制御点付き曲線として読み取る処理を追加しました。SVGのpath（M/L/H/V/C/S/Q/T/A/Z）、rect、circle、ellipse、polygonの閉じた輪郭を取り込みます。
- フォルダーのネストと重複境界の除去、リンク付きクローンへの自動反映を維持します。
- 閉じた輪郭を持たない線画や非対応の特殊変形は、対象のレイヤー名と理由をメッセージに表示します。SVGのフィルター・文字・一部の複雑なクリップ表現は未対応です。


## 線画を含む外周統合（2026-11-07）

- フォルダー内の**直線・フリーハンド（線画）・ベジェ線画**を、線幅を持つ閉じたベクター輪郭に変換して外周統合の対象に加えました。元の線画・頂点・レイヤーは変更しません。
- 同一フォルダー内で重なる線と塗り図形の内部境界を消し、クローンのアウトラインを外周だけに描画します。元の線画を変形した場合もクローン描画を再計算します。
- 単独の線画レイヤーのクローンも線の外形を参照したアウトラインを描画します。
- **注意：** 線の中心パスはベジェのまま参照しますが、幅を持つ外周はベクター線分・丸キャップによる近似です。細密なフリーハンド線や自己交差で厳密な曲線オフセットを保証しません。線種が破線・点線の場合は外周を連続した線として扱います。SVG内の開いた線や特殊変形は対象外です。


## リンク付きクローンの修正
- クローンの生成と描画では外周統合・点列変換・ラスター輪郭抽出を一切使用しません。
- 元のレイヤー／フォルダーを毎フレーム直接参照するため、形状・位置・キーフレーム・頂点編集を反映します。

- SVG/統合済み素材は編集可能な内部パスに変換せず、元の表示内容を参照します。


## アウトライン線の位置（現在の仕様）

レイヤー／フォルダー／リンク付きクローンを選び、右側プロパティの「アウトライン」または「フォルダーのアウトライン」「外周アウトライン」で **内側／中央／外側** をラジオボタンで選択します。初期値は中央です。従来の「≡ → 選択レイヤー／フォルダーからアウトラインオブジェクトを生成」は削除しました。新しいレイヤーを作る機能ではなく、選択中のオブジェクトの既存アウトライン表示を調整する機能です。

閉じたベクター形状については元のベジェパスは変更せず、ストロークの表示範囲をクリップ／マスクすることで線の内外位置を切り替えます。開いた線画パスには内外の領域がないため中央として描画します。クローンは元の形状・色へのリンクを維持します。なお、破線・点線の見た目は線種の設定に依存します。

### クローン外周線のドラッグ中の表示安定化（2026-11-07）
- ドラッグ中の交点計算で生じる小さな座標差に対し、外周のベジェセグメントの接続を許容誤差内で補正します。
- 閉じていない線のつながりを外周として採用しないようにしました。
- 計算が一時的に失敗した際には、直前に正しく生成できた外周パスを利用します。元フォルダー全体の移動時には、その変形をキャッシュにも反映します。
- クローンの独立した塗り・アウトライン設定、元オブジェクトへの追従は従来どおりです。


## クローン外周のドラッグ中表示（2026-11-07 修正）

- 元図形をドラッグ・回転・拡大縮小している間は、曲線の交点演算を一時的に使用せず、SVG上で元の描画結果のアルファ境界から外周線を合成します。移動中の内部境界表示や線の分断を抑えるためのプレビュー処理です。
- 操作終了後は従来のベジェ外周パス描画へ戻ります。元レイヤーやクローンのパスは書き換えません。
- ドラッグ中の破線・点線は外周プレビューでは実線に近い表示になる場合があります。操作確定後に設定した線種へ戻ります。


## 選択オブジェクトの整列・分布

左のレイヤーパレットでレイヤーを2個以上チェックし、左上の「≡」→「整列・分布」を開きます。
整列6種類（左／左右中央／右／上／上下中央／下）、分布6種類（左端／横中心／右端／上端／縦中心／下端）、等間隔2種類（横／縦）を利用できます。分布・等間隔には3個以上が必要です。選択したフォルダーは一体として扱われます。Undo、現在のキーフレームへの反映に対応します。

## 3D編集画面：地面・パースグリッド

- 右のプロパティに「地面を表示」「パースグリッドを表示」を追加しました。
- 地面（XZ平面）で接地位置を把握でき、パースグリッドは奥行き確認用に表示できます。
- それぞれのチェック状態は3Dレイヤー内に保存されます。
- 地面・グリッドは編集補助で、レイヤーへ反映する透過画像には含まれません。
